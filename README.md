# Coordinated EV Charging and Discharging for Smart Parking Lots

Paid research placement supervised by Dr. Maher Azzouz (Smart Grid Lab, ECE), University of Windsor.

Building a Python-based central controller that schedules charging for individual EVs in a small lot under a shared lot power limit, using published real-world charging data. Starting with minimizing electricity cost while balancing driver charge targets and charger utilization.
